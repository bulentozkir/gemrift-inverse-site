This notice explains the website as it works today and distinguishes it from the game still being developed. It does not import the original Gemrift app's Store identity, licensing, or recording features.

1. A static website, without trackers

This website does not require an account, run advertising or analytics scripts, or use tracking cookies. It does not store information in localStorage, sessionStorage, or a browser database. Fonts, images, and scripts are served with the site rather than loaded from third-party font or analytics services.

The theme uses your device's color preference or a scoutTheme URL parameter. Changing the theme changes that parameter; it does not create a browser-storage record.

2. GitHub Pages hosting

GitHub serves this website. GitHub may process technical request information, such as your IP address, for hosting, security, and service operation. That processing is governed by the GitHub General Privacy Statement, not a promise that visiting a hosted page creates no server logs.

Links to GitHub, the original Gemrift website, or other external destinations take you to services with their own policies.

3. Support is your choice

The support form prepares a downloadable email draft entirely in your browser. The form does not upload the message or attachment, submit it to a support server, or send an email automatically.

If you choose to send the draft or email directly, the publisher receives the email address and any message, attachment, or other information you include. That information is used to respond to your request and investigate the reported issue. Your email provider also processes the message under its own policies. Please omit sensitive information and redact screenshots or logs before sending them.

GitHub issues are public. Use email rather than the public issue tracker for private matters.

4. The current development build

Gemrift inverse is a Windows game in development. The current campaign keeps settings and progress locally on the player's device. It contains no shipped solution recordings; the current campaign does not start the inherited Microsoft Store licensing helper or download walkthrough recordings.

These are development-build details, not a guarantee about an unreleased final product. No public Store listing, pricing, or launch date is announced on this site. This notice will be reviewed when release behavior is finalized.

5. Questions and updates

For privacy questions or requests concerning a support message you sent, contact bulentozkir@hotmail.com. We may update this notice when the site or game changes; the effective date will identify the latest version.
